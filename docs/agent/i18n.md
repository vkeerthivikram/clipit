# i18n rules

- All UI strings live in `i18n/<locale>/clipit.ftl` (Fluent). English is
  the source of truth and fallback.
- `all_locales_cover_every_message` fails when any locale misses an ID or
  gains a stray one. Adding a string means adding it to en and every other
  locale in the same change.
- Pass numbers as numbers (`fl!("expire-days", days = n)`) — numeric args
  are what make CLDR plural selects work.
- `fl!` returns `String` and wraps interpolations in U+2068/U+2069
  isolation marks; strip those before comparing in tests.
- libcosmic exports its own `fl!` bound to libcosmic's strings; Clipit
  strings use `crate::fl!`.
- Keep `history.rs` returning bare data ("now", "5m") so it stays
  translatable; localize relative time in `app.rs::localized_time`.
